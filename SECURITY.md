# Security Policy

This repository contains instruction content, templates, and validation scripts. It does not run an agent service or store credentials.

## Reporting a vulnerability

Use GitHub's **Security → Report a vulnerability** flow so the report stays private. Private vulnerability reporting is enabled for this repository as part of the release setup.

If that button is temporarily unavailable, open a minimal public issue that contains **no vulnerability details, credentials, private prompts, or exploit steps** and ask the maintainer to provide a private reporting channel.

Supported release line: `v1.x`.
